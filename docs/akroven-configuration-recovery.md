2. Exercise separate build and runtime proofs. The deployed app should contain the test `NEXT_PUBLIC_APP_URL` and reach test Clerk. The runtime must access the isolated Redis pair. Verify domain ownership, sender and callback registrations in their provider consoles. The legacy `/api/health` status gives deployment and storage readiness separately.
